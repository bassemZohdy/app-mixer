# Flutter renderer: static prototype

`adapters/flutter` contains a Flutter package with an initial A2UI v0.9.1 renderer for Text, Column, Row and Card. It accepts create, incremental component and data-model updates, and delete surface messages for the App Mixer catalog or the basic catalog identifier. Accepting a catalog identifier does not imply support for the full catalog.

A host supplies `AppMixerA2UI` with `subscribe`, a function that receives a message callback and may return an unsubscribe callback, and `onError`. A new subscription must replay the current state. The widget unsubscribes on replacement or disposal and ignores late messages. Updates are validated and applied atomically, with limits on surfaces, components, tree depth and expanded size. Incoming text is rendered as text and never executed.

Text supports literal values and absolute JSON pointer bindings, and model updates reject prototype-sensitive paths. TextField, Button, actions, and the full web catalog are not yet supported. The model uses JSON values; array element deletion is represented as null. Typography and layout parity are not complete: explicit `stretch` alignment is rejected and the default cross-axis alignment is centered to avoid unbounded layout errors. Platform integration and accessibility testing remain future work. P2-01 remains open until Flutter and React Native cover the supported web catalog and cross-platform parity is verified.

The Flutter workflow runs only for pull requests changing the Flutter package or its workflow. It downloads the pinned Flutter SDK and verifies its published SHA-256, then runs `flutter analyze` and widget tests. A shared binding fixture is also checked against the web and React Native state implementations. On a machine with Flutter 3.35.5 installed, run `flutter pub get`, `flutter analyze`, and `flutter test` from `adapters/flutter`.
