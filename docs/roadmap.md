# Roadmap

## M0 — Initial scaffold
- [x] TypeScript strict monorepo and versioned application definitions
- [x] Atomic typed draft patches and immutable in-memory publication
- [x] Minimal standalone HTTP app scaffold with chat placeholder and published pages
- [x] Automated unit tests
- [ ] Full AG-UI/A2UI integration

## M1 — Agent-native development
- [ ] Durable repository (SQLite default)
- [ ] Optional Control Plane and isolated Runtime Plane
- [ ] Development Agent, drafts, preview/publish UI
- [ ] Runtime agent with configurable LLM and AG-UI stream
- [ ] A2UI registered renderer/components
- [ ] OpenAPI capability registry and authorization
- [ ] Two-level caching and Docker Compose

## M2 — Portability and production
- [ ] Angular, React, React Native and Flutter adaptors
- [ ] Extensions/manifest/compatibility checks
- [ ] Staged data and offline synchronization
- [ ] Identity, audit, telemetry, migration, rollback, Kubernetes deployment

Checked items refer only to the initial foundation slice, not production readiness.
